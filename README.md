# library-form-java

Aplicação desktop desenvolvida em Java para gerenciamento de acervo de biblioteca, leitores e operações de empréstimo e devolução de livros.

## Sobre o Projeto

Aplicação desktop desenvolvida em Java para gerenciamento de acervo de biblioteca, leitores e operações de empréstimo e devolução de livros.

## Tecnologias Utilizadas

- Java
- Java Swing / JavaFX (conforme interface implementada)
- JDBC
- MySQL

## Funcionalidades

- Cadastro de livros
- Cadastro de leitores
- Registro de empréstimos
- Registro de devoluções
- Consulta do acervo
- Relatórios simples, conforme implementado

## Arquitetura do Projeto

Arquitetura desktop com organização MVC e padrão DAO (Data Access Object), conforme a estrutura descrita para o projeto. A separação facilita organizar a interface, as regras da aplicação e o acesso aos dados.

## Banco de Dados

MySQL

## Como Executar

1. Clone este repositório.
2. Abra o projeto em uma IDE compatível com Java, como Apache NetBeans.
3. Verifique a versão do JDK e as dependências necessárias.
4. Crie o banco MySQL e configure os parâmetros de conexão JDBC.
5. Execute os scripts SQL existentes, se houver.
6. Compile e execute a aplicação pela IDE ou pelo mecanismo de build configurado no projeto.

## Aprendizados

- Desenvolvimento de aplicações desktop com Java.
- Construção de interfaces gráficas.
- Acesso a banco de dados com JDBC.
- Organização do código com MVC e DAO.
- Implementação de operações de cadastro e controle de empréstimos.
